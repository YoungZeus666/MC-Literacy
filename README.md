# 我的世界之认字大冒险

面向幼小衔接的汉字认读小游戏。孩子大声读出方块上的字，家长点对或错；读对的字会变成绿宝石，用来盖一座越来越大的村子，同时击退来犯的僵尸。

整个游戏就是一个 `index.html`，用浏览器直接打开即可，不需要安装、不需要网络。

## 怎么玩

1. 用浏览器打开 [`index.html`](./index.html)。
2. 孩子读出中间大方块上的汉字。默认不显示拼音，避免只盯着拼音认字。
3. 家长点按钮：
   - **🔊 朗读**：读出这个字（系统 `speechSynthesis`），同时显示拼音和组词。
   - **👁 看拼音**：显示当前字的拼音和组词（如「人 → rén · 大人」）。
   - **✅ 读对啦！挖方块**：+1 绿宝石，村庄建造 +1，最近的僵尸被击退或消灭，约 0.9 秒后自动进入下一个字。
   - **❌ 读错了 · 僵尸前进**：僵尸向房子逼近。连续答错积累僵尸波次，满 5 波僵尸攻到房子，进入**错题复习**。
   - **➡️ 跳过这个字**：换下一个字，不给宝石、不涨建造。
   - **🔄 重置全部进度**：清空绿宝石、村庄和关卡（会二次确认）。

进关、章节建成时会弹出提示，点「继续」再往下。全部 8 关读完会通关。点「再来一次」会新开一座空村，绿宝石从 0 再攒；通关窗里会写上轮盖到哪。

进度存在浏览器 `localStorage`（键名 `mc_read_game_v2`）里，关掉页面再打开会接着上次的关卡、字序、错题和村庄。

## 僵尸系统

- 每答错一次，僵尸向房子逼近（70% 概率已有僵尸前进，30% 概率新僵尸从外围入场）。
- 僵尸有 **4 条行进路线**（左前、右前、左墙根、右墙根），每条路线 6 个站位，最多同时 24 只僵尸。
- 连续答错积累 **僵尸波次**（进度条显示 0/5），满 5 波僵尸攻到房子，强制进入错题复习。
- 答对时，离房子最近的僵尸后退一步；退无可退时被消灭（播放倒下动画）。

## 炮塔防御

- 当僵尸波次 ≥ 5 或在错题复习中，解锁 **炮塔** 区域。
- 花费 **3 💎** 建造一座炮塔（最多 5 座），每建一座僵尸波次 -1。
- 炮塔用于在僵尸围困时击退僵尸，争取复习时间。

## 村庄建造

村庄在同一块画布上逐关扩建，8 章对应 8 种建造内容：

1. **🏠 小屋**：18 块墙壁 + 屋顶渐变填充 + 旗帜
2. **🪨 石墙**：8 块石子路 + 15 根栅栏 + 12 朵花
3. **🏖️ 沙地庭院**：16 块地砖 + 4 棵仙人掌 + 水井（4 部分渐进）+ 2 棵棕榈 + 3 个沙滩装饰
4. **⛏️ 铁栅栏**：每字一根铁条
5. **💎 绿宝石塔**：每字一颗绿宝石
6. **🔴 红石机关**：每字一盏红石灯
7. **💠 钻石城墙**：每字一块钻石
8. **🖤 黑曜石堡垒**：全部完成后激活黑曜石护盾

每关的建造上限 = 该关字数，读对一个字 = 建造 +1。

## 错题本

读错的字记进 📝 错题本。僵尸波次满 5 后，先复习这些错字，本关认字进度保留。读对就从错题本移除；过关前如果还有错字，会先复习再进下一关。

## 音效

全部使用 Web Audio 合成，无需外部音频文件：

- 🔨 **挖方块**：方波短促音（答对时）
- 💎 **获得绿宝石**：正弦波双频上扬（答对后）
- ❌ **答错**：三角波低频（答错时）
- 👹 **僵尸低吼**：锯齿波下滑（答错时）
- 💥 **击退/消灭**：方波上扬（答对击退僵尸时）
- 🏆 **通关胜利**：四音阶上行和弦

## 运行方式

没有构建步骤，也没有依赖。用浏览器打开 [`index.html`](./index.html) 即可。

页面按约 480px 宽的卡片适配手机。挖方块音效用 Web Audio 合成，汉字朗读用系统 `speechSynthesis`；都需要先点一次按钮（浏览器自动播放策略）。

## 仓库结构

```
cube-char/
├── index.html   # 游戏本体（样式、字库、拼音、组词、逻辑）
└── README.md
```

改字库、拼音或组词，直接编辑 `index.html` 里的 `levels`、`PINYIN`、`COMPOUND`。建造上限等于该关 `words.length`，增删字数时进度分母会跟着变。

## 语音优化

朗读功能优先选择普通话声音：
1. Google 普通话（Chrome 最稳）
2. 系统「婷婷」语音
3. 回退到 `zh-CN` 中国大陆普通话

自动排除粤语和台湾腔语音。
