# 我的世界之认字大冒险

面向幼小衔接的汉字认读小游戏。孩子大声读出方块上的字，家长点对或错；读对的字会变成绿宝石，用来盖同一座越来越大的村子。

整个游戏就是一个 `index.html`，用浏览器直接打开即可，不需要安装、不需要网络。

## 怎么玩

1. 用浏览器打开 [`index.html`](./index.html)。
2. 孩子读出中间大方块上的汉字。默认不显示拼音，避免只盯着拼音认字。
3. 家长点按钮：
   - **朗读 / 看拼音**：读出这个字，并显示拼音和组词（如「人 → 大人」）。
   - **读对啦！挖方块**：+1 绿宝石，本关建造 +1，僵尸剪影清掉，约 0.9 秒后自动进入下一个字。同一字不能连点刷宝石。
   - **读错了 · 僵尸前进**：方块右侧亮起一个走近的僵尸剪影。满 3 个进入**错题复习**（不会把本关进度清零）。
   - **跳过这个字**：换下一个字，不给宝石、不涨建造。
   - **重置全部进度**：清空绿宝石、村庄和关卡（会二次确认）。

进关、小屋/院子/守夜刚建成时会弹出提示，点「继续」再往下。三关读完会通关。点「再来一次」会**新开一座空村，绿宝石从 0 再攒**；通关窗里会写上轮盖到哪。

进度存在浏览器 `localStorage`（键名 `mc_read_game_v2`）里，关掉页面再打开会接着上次的关卡、字序、错题和村庄。

## 三关

| 关卡 | 主题 | 字数 | 画面 | 本关建造 |
|------|------|------|------|----------|
| 第一关 | 草方块入门 | 30 | 草绿方块 | 小屋 30（墙 + 屋顶） |
| 第二关 | 铁矿层进阶 | 35 | 铁矿方块 | 院子 35（小路 + 栅栏 + 花） |
| 第三关 | 汉字僵尸大作战 | 20 | 苔石方块 | 守夜 20（火把 + 旗帜） |

顶栏 **✅ 读对数** 和下面的建造进度用同一套数字（只算读对，跳过不算）。上一关盖好的还在，进下一关只长新的一层；本关盖完后多出来的宝石只加头顶的 💎，不会提前长出下一关的东西。

## 错题本

读错的字记进 📝。僵尸走近 3 步后，先复习这些错字，本关认字进度保留。读对就从错题本拿掉；过关前如果还有错字，会先复习再进下一关。

## 运行方式

没有构建步骤，也没有依赖。用浏览器打开 [`index.html`](./index.html) 即可。

页面按约 480px 宽的卡片适配手机。挖方块音效用 Web Audio 合成，汉字朗读用系统 `speechSynthesis`；都需要先点一次按钮（浏览器自动播放策略）。

## 仓库结构

```
cube-char/
├── index.html   # 游戏本体（样式、字库、拼音、组词、逻辑）
└── README.md
```

改字库、拼音或组词，直接编辑 `index.html` 里的 `levels`、`PINYIN`、`COMPOUND`。建造上限等于该关 `words.length`，增删字数时进度分母会跟着变。
